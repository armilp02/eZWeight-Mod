### 📦 Version 1.8.0

- 🐛 Fixed: TACZ guns no longer gain weight when dropping below half ammo with eZWeight and Gun Durability installed.
- 📦 Added:
    -  New Backpack System: weight reduction, custom % and max weight per backpack. `Use: /ezweight backpack <reduction%> <max_weight> command`
    -  New command that can now override any player's max weight in-game. `/ezweight setmaxweight <player> <weight> and /ezweight resetmaxweight <player>`
    -  Minor change; add dynamic weight true by default.
