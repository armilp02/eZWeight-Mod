
# eZWeight

eZWeight is a customizable weight system mod that adds a touch of realism and is perfect for survival or roleplay servers — or both!

Players must manage their inventory carefully to avoid becoming overloaded and suffering penalties as a result.

> Fully configurable!

## Main Features

- Item-based weight system, fully customizable via JSON files.
- ⚖️ Dynamic penalties when overweight, such as no jumping or taking damage.
- Compatible with backpack mods and Curios, automatically adjusting the total weight with extended inventories.
- 🖥️ Integrated HUD, with visual indicators both on-screen and in the inventory for intuitive weight management.
- ⚖️ Reworked player weight calculation using dynamic weight calculations:
    - Base weight
    - Food level
    - Strength effects
    - Crouching
    - Armor weight
- 🔫 TACZ Guns compatibility with guns, ammo, and attachments.
- 🎒 Backpacks weigh 20% less by default.
- ⚙️ Configurable backpack settings:
    - Custom weight reduction percentage
    - Custom maximum weight per backpack

## Customization

eZWeight provides a flexible configuration through four core files:

### client-config.toml
Adjusts HUD visibility and style.

### config.toml
Controls base player weight and global penalties.

### levels.json
Defines weight thresholds and associated negative effects.

### items.json
Defines item weights and allows full customization of inventory weight values.
